# Hamriley portfolio

A dependency-free, responsive portfolio foundation using HTML, CSS, and JavaScript.

## Preview

Open `index.html` directly in a browser, or serve this directory with any static HTTP server. For example, if Python is available:

```powershell
py -m http.server 4173 --bind 127.0.0.1
```

Then visit http://127.0.0.1:4173.

## Edit

- `index.html`: profile, projects, experience, contact details.
- `styles.css`: typography, responsive layout, and colors.
- `script.js`: progressive entrance animation and footer year.
- `CONTENT-CHECKLIST.md`: missing assets and details to add later.

Project artwork is conceptual, not a product screenshot. No packages, account, build step, or backend are required. This foundation has not been deployed.
